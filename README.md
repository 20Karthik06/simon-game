# Simon Game

A browser-based memory game built using HTML, CSS, and JavaScript. Repeat the sequence of colors and sounds for as long as you can!

## Features

- Interactive color buttons
- Increasing difficulty as the sequence grows
- Keyboard-friendly start interaction (if supported by your implementation)
- Score and game-over feedback

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Open the game in your browser.
2. Start the game using the interaction provided.
3. Watch the sequence of colors.
4. Repeat the sequence by clicking the buttons in the same order.
5. Each successful round adds another step to the sequence.
6. The game ends when you choose the wrong sequence.

## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/20Karthik06/simon-game.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
